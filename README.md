# Google 收錄查詢工具

想知道自己的文章有沒有出現在 Google 上嗎？這個工具可以一次貼上很多網址，幫你逐條查出哪些已經被 Google 收錄、哪些還沒有。

它特別適合經營多個 WordPress 網站的人。你不需要每個網站都開 Google Search Console 權限，只要有網址就能查。

## 它能幫你做什麼

- **批次查收錄**：一次貼上幾十、幾百條網址，自動逐條查詢。
- **看每個網站的狀況**：依網域分開統計，一眼看出哪個網站的收錄率比較差。
- **抓文章發布日期**：自動找出每篇文章是哪天發布的，算出已經發布幾天。
- **告訴你下一步**：沒被收錄的文章，會標出是「剛發布，再等等」還是「發布很久了，需要主動提交」。
- **匯出成表格**：結果可以存成 CSV，用 Excel 或 Google 試算表打開。

## 開始之前要準備什麼

1. **一個 ScrapingDog 帳號和 API key**：這個工具透過 ScrapingDog 幫你查 Google。到 [scrapingdog.com](https://www.scrapingdog.com/) 註冊後，在後台可以找到一串叫做 API key 的密碼。
2. **一個瀏覽器**：Chrome、Edge、Safari 都可以。

不需要安裝任何程式。

## 怎麼使用

### 第一次使用

1. 用瀏覽器打開 **Google收錄查詢.html**，直接雙擊檔案就可以。
2. 在「ScrapingDog API key」欄位貼上你的 API key，按「儲存」。

API key 只會存在你這台電腦的瀏覽器裡，下次打開不用再輸入。

### 開始查詢

1. 把要查的網址貼進「網址清單」。一行一條，也可以直接從 Excel 或 Google 試算表整欄複製貼上。
2. 選擇地區。預設是台灣，如果你的網站主要給其他國家的人看，就選那個國家。
3. 按「開始查詢」。
4. 畫面會跳出確認視窗，告訴你這次大概要花多少額度。確認沒問題再按「確定查詢」。
5. 等表格跑完就好。查詢中可以隨時按「停止」。

重複的網址會自動合併。網址有沒有 www、結尾有沒有斜線，都會當成同一條。

### 看結果

結果分成兩個部分。

**分網域統計**：每個網站一行，列出網址數、已收錄、未收錄、需主動提交的數量和收錄率。點某個網站，下面的明細就只顯示那個網站的文章。

**明細**：每條網址一行，包含：

- **狀態**：已收錄或未收錄。
- **發布日期**：文章哪天發布、幾天前發布。
- **建議**：只有未收錄的文章才會顯示，說明見下一段。

上方的按鈕可以篩選狀態，也可以一鍵複製「需主動提交」或「未收錄」的網址。

### 建議欄怎麼看

| 建議 | 意思 | 你可以怎麼做 |
|---|---|---|
| 剛發布 | 發布 7 天內還沒收錄 | Google 通常需要幾天到一兩週，先等等 |
| 需主動提交 | 發布超過 7 天還沒收錄 | 到 Search Console 提交網址，或檢查內部連結和 sitemap |
| 查不到日期 | 找不到這篇文章的發布日期 | 手動確認文章日期 |

「幾天內算剛發布」可以在「進階設定」裡調整，改完表格會馬上更新，不用重查。

### 匯出結果

- **匯出 CSV**：每條網址的完整結果。
- **匯出網域統計 CSV**：每個網站的統計數字。

用 Excel 直接打開中文也不會亂碼。

## 費用說明

這個工具本身免費，花費來自 ScrapingDog 的額度。ScrapingDog 用 credits 計算用量。

| 動作 | 花費 |
|---|---|
| 查一條網址有沒有收錄 | 5 credits |
| 抓 WordPress 文章的發布日期 | 免費 |
| 抓非 WordPress 網站的發布日期 | 1 credit |

以 ScrapingDog 的 Lite 方案為例：每月 40 美元有 200,000 credits，大約可以查 40,000 條網址。換算下來，查一條大約台幣 3 分錢。

如果不想花額度抓非 WordPress 網站的日期，可以到「進階設定」把「用 ScrapingDog 抓網頁」關掉。

## 省錢小技巧

- **3 天內查過的不再扣錢**：同一條網址 3 天內再查，會直接用上次的結果，表格會標「快取」。
- **想拿最新結果**：勾選「不用快取，全部重查」。
- **先試用**：「進階設定」裡有示範模式，用假資料體驗所有功能，完全不花額度。

快取只存在你這台電腦的瀏覽器裡。換電腦、換瀏覽器或清除瀏覽器資料後，就要重新查。

## 常見問題

**查到「未收錄」就一定沒被收錄嗎？**

不一定。這個工具是模擬在 Google 搜尋 `site:網址`，偶爾會漏。如果你覺得結果怪怪的，隔幾天再勾「不用快取」重查一次。

**為什麼有些文章抓不到發布日期？**

工具會先問 WordPress，問不到再去讀文章網頁裡的日期標記。如果網站關掉了 WordPress 的資料介面，或文章網頁裡本來就沒有日期，就會抓不到。

**畫面跳出「API key 無效或額度已用完」怎麼辦？**

先確認 API key 有沒有貼錯。沒貼錯的話，到 ScrapingDog 後台看看額度是不是用完了。

**同時查詢數要設多少？**

維持預設的 3 就好。調高會比較快，但可能被 ScrapingDog 限速。這個設定不影響花費。

**我的 API key 安全嗎？**

API key 只存在你的瀏覽器，查詢時直接送到 ScrapingDog，不會經過其他地方。在公用電腦上使用時，記得取消勾選「記在這台電腦」，用完按「清除」。

## 進階：命令列版

資料夾裡的 `check_index.py` 是給熟悉電腦操作的人用的版本。它可以直接讀網站的 sitemap，一次檢查整個網站的所有文章，不用自己整理網址清單。

使用前要先把 `.env.example` 複製成 `.env`，填入 API key。接著在終端機執行：

```bash
python check_index.py --sites sites.txt --dry-run
```

`sites.txt` 裡一行寫一個網域。加上 `--dry-run` 只會算出預估額度，不會真的查詢。確認後拿掉 `--dry-run` 再執行一次。

輸入 `python check_index.py --help` 可以看到所有選項。
